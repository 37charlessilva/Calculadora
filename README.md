# Calculadora em Python com Flet

Uma calculadora simples feita em Python utilizando o framework Flet para criar a interface gráfica.

## Funcionalidades

- Operações básicas:
  - Soma (`+`)
  - Subtração (`-`)
  - Multiplicação (`*`)
  - Divisão (`/`)
- Botão de apagar
- Interface responsiva
- Botões personalizados usando orientação a objetos
- Uso de herança e sobrescrita de métodos

## Tecnologias utilizadas

- Python
- Flet
